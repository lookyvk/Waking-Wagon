User Guide

Setting the Timer

To set the timer, press either A or B. Edit mode let's you set the timer to your desired time.

Edit mode

Edit mode allows you to adjust the timer settings to your preference. PIN A3 and A2 toggles edit mode on and off. When in edit mode, you can use the buttons to increase or decrease the timer duration.

To Stop the Timer

When the alarm goes off, you have to catch the Waking Wagon and click on the button on top of the vehicle. This will stop the timer and the Waking Wagon will return to its previous state. PIN A4 and A5 are used to set the alarm off when it goes off.
